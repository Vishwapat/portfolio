# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be kind, patient, and assume good intent.
- Critique code and ideas, never people.
- No harassment, discrimination, or personal attacks, in any form.
- Respect privacy. Do not publish anyone's personal information.

## Enforcement

Report unacceptable behaviour to the maintainer, [@Vishwapat](https://github.com/Vishwapat),
through a [direct message on LinkedIn](https://www.linkedin.com/in/vishwa-p-518408328/).
Reports are handled confidentially. The maintainer may remove, edit, or reject
comments, commits, issues, and pull requests that do not follow this code, and
may block repeat offenders, following the Contributor Covenant enforcement guidelines.
